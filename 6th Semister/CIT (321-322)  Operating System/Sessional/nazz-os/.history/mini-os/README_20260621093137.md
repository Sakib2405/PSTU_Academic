# NazzOS

NazzOS (formerly MiniOS) is an interactive terminal-based operating system simulator used for educational purposes.

Features
- Process scheduling simulations (FCFS, SJF, SRTF, Round Robin, Priority, MLFQ)
- Memory management demos (paging, replacement algorithms, buddy allocator)
- Virtual file system (inodes, FAT, permissions, tree view)
- Disk scheduling algorithms (FCFS, SSTF, SCAN, C-SCAN, LOOK, C-LOOK)
- Deadlock detection & recovery (Banker's algorithm, RAG)
- Synchronization demos (Dining Philosophers, Producer-Consumer, Reader-Writer)
- Live dashboard and learning modules

Requirements
- Python 3.10+
- Packages: `rich`, `prompt_toolkit`, `psutil`

Quick start
1. Install dependencies:

```bash
pip install rich prompt_toolkit psutil
```

2. Run NazzOS:

```bash
python main.py
```

Notes
- The interactive prompt appears as `NazzOS [/]>{` cwd `}`. Use `help` to list available modules and `help <module>` for details.
- Desktop entry included: `NazzOS.desktop` (for Linux desktop integration).
- This project was renamed from MiniOS → NazzOS; source strings and assets were updated accordingly.

Web UI (FastAPI + xterm.js)
---------------------------------
- A simple web frontend is provided at `web/index.html` and a websocket server at `web.py` which spawns a PTY running `main.py`.
- This approach requires a POSIX environment (Linux or WSL). On Windows native Python the PTY/fork approach will not work — use WSL or deploy to a Linux host.

Quick web setup (Linux / WSL):

```bash
pip install -r requirements.txt
python web.py  # or use: uvicorn web:app --host 0.0.0.0 --port 8000
```

Open `http://<host>:8000` in your browser. For production, run behind HTTPS with auth and container isolation.

Security note: exposing an interactive shell over the network is dangerous. Only use inside trusted, isolated environments or for demos with proper authentication and network restrictions.
